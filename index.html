Office基本操作まとめ

この資料は、Microsoft Officeの基本操作について学ぶための講座内容をまとめたものです。

1. Office共通操作

Microsoft 365とは

Microsoft 365は、クラウドサービスであり、インターネットを介してソフトウェアやサーバー環境を提供します。どんな端末や場所でも利用可能です。

  • OfficeはMicrosoft 365に含まれるアプリ群の総称
  • 有料版と無料版があり、大学経由で有料版を利用可能
  • 講座ではアプリ版を使用

PowerPoint画面の構成

  • タブ: 機能別の集合体
  • リボン: タブをクリックすると表示される領域
  • グループ: 機能をさらに細分化した集合体
  • アイコン: 実際の操作ボタン

2. ファイルの保存方法

  • クイックアクセスツールバー: 自動保存や手動保存が可能
  • ファイルタブ → 名前を付けて保存: 新しいファイルを保存
  • 保存場所: OneDrive（クラウド）、PC（参照）

上書き保存

  • ファイルタブ → 上書き保存
  • ショートカット: Ctrl + S
  • クイックアクセスツールバー

3. オブジェクトの操作

  • 選択方法: ドラッグで範囲選択、クリックで選択
  • 操作方法:
    • 動かす → ドラッグ
    • 変更する → 上書き
    • 削除する → Deleteキー
    • 実行する → ダブルクリック
  • 右クリックで操作メニュー表示

共通機能

  • 元に戻す / やり直す
  • クリップボード: Ctrl + X（切り取り）、Ctrl + C（コピー）、Ctrl + V（貼り付け）

4. ファイルの出力（印刷・PDF化）

印刷

  • ファイルタブ → 印刷 → 詳細設定（部数・方法）

PDF化

  • PDFはレイアウト崩れを防ぐための形式
  • ファイルタブ → エクスポート → PDF形式で保存
  • 注意: PDF化後は基本的に編集不可
